# CS-454-Proj-02b
Goals of the project      Implement Karatsuba algorithm to multiply two integers A and B whose values are less than or equal to 10000.      Implement Exponentiation algorithm to evaluate A^B, where A and B are two integers whose values are less than or equal to 10000. The maximum value of A^B can be 10000^10000 which has 40001 digits.
